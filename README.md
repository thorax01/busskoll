# busskoll

Android/iPhone-app (PWA) att öppna på morgonen: vädret i Svedmyra och om det är
störningar eller förseningar på buss 161 (Svedmyra mot Majstångsvägen) och
buss 163 (Svedmyra mot Fruängen), med de närmaste avgångarna, så att man kan
välja vilken buss som passar bäst. Variant av morgonkoll.

- `index.html` – appen; plats och linjer (`LINJER`) ställs in överst i skriptet
- Väder: [Open-Meteo](https://open-meteo.com/) (ingen nyckel)
- SL: Trafiklabs öppna API:er för störningar och realtidsavgångar (ingen nyckel)
- `scripts/ikoner.py` – ritar ikonerna (`python scripts/ikoner.py`)
